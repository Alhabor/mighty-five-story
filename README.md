# Mighty Five

A one-page team introduction created for NYU Shanghai DABC Orientation 2026.

## Project

This repository presents the Mighty Five team and its shared team structure in
a single static page.

## File

- `index.html` — the complete page, including its text, styles, and badge graphic.

## View locally

1. Open the repository folder on your computer.
2. Open `index.html` in a web browser.

The page is intended to be viewed directly from the local file.
